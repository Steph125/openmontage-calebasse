All generated by `hf-build/build.mjs` (`FORMAT_SPECS`): the 9:16 master is the design frame, shown through a
uniformly scaled window (never stretched). Off-stage waits and the drag-off distance are pushed out where the
canvas is wider than the frame, with stride cadence scaled to match; the masters stay byte-identical.
`node hf-build/build.mjs 1080x1080` rebuilds a single format.

## Re-render
- **Remotion** — `video_compose` atelier path (`entry: index.tsx`, `composition_id`, `props_path: artifacts/props.json`).
  OneDrive turns synced `public/` files into reparse points that Remotion's public-dir server 404s:
  copy `public/` to a plain folder under `%TEMP%` first and pass that as `public_dir`.
- **HyperFrames** — edit `hf-build/build.mjs` (never the generated `index.html`), run `node hf-build/build.mjs`,
  then `npx hyperframes check` in `hf-a`/`hf-c` and render through `video_compose`
  (`render_runtime: hyperframes`, `composition_mode: atelier`, `workspace_path`).
  `hyperframes doctor` takes ~24 s here; the tool's 20 s probe can flap.
